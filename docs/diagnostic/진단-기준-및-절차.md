# 무료 진단 — 판정 기준 및 작성 절차 (내부용)

작성일: 2026-07-29

이 문서는 **대표 본인이 보는 기준표**다. 고객에게 전달하는 것은 `템플릿-홈페이지진단.md` / `템플릿-검색노출진단.md`.

## 왜 진단부터인가

콜드 접촉의 첫 문장이 "홈페이지 제작 문의 드립니다"(파는 것)이면 광고로 읽혀 삭제된다. "원장님 홈페이지 전화번호가 휴대폰에서 눌러도 전화가 안 걸립니다"(주는 것)이면 무시하기 어렵다. 이미 노동이 들어간 증거라서다.

그리고 진단이 **견적의 근거**가 된다. 근거 없는 280만원은 "돈 달라"로 읽히지만, 구멍 6개를 지목한 뒤의 280만원은 "이걸 막는 비용"이 된다.

## 실패 모드 방어 (PLAN.md 하드룰)

> "그 주 신규 접촉 0이면 그 주 무상 제작도 0" — 제작이 영업의 도피처가 되는 것이 유일한 실패 모드

진단도 같은 위험이 있다. 그래서 고정한다.

- **작성 시간 상한: 홈페이지 진단 60분 / 검색 노출 진단 30분.** 넘으면 항목을 줄이고 그대로 보낸다.
- **항목 고정.** 매번 같은 것만 본다. 흥미로운 걸 발견해도 "부가 관찰"에 한 줄로 끝낸다.
- **제작·수정은 하지 않는다.** 진단은 지적까지다. 고쳐주기 시작하면 무상 제작이다.
- **주간 진단 상한 5건.** 그 주 신규 접촉이 5건 미만이면 진단도 그 수만큼만.

## 두 종류

| | 대상 | 등급 | 수 | 상한 |
|---|---|---|---|---|
| **Type B** 홈페이지 진단 | 홈페이지 있음 | B·C | 27곳 | 60분 |
| **Type A** 검색 노출 진단 | 홈페이지 없음 | A | 24곳 | 30분 |

Type A는 진단할 사이트가 없으므로 **"학부모가 검색했을 때 무엇을 보는가"**를 진단한다.

# Type B — 홈페이지 진단 6항목

각 항목은 세 조건을 만족한다: ① 객관적으로 측정된다 ② 원장님이 매출과 연결해 이해한다 ③ 대표가 고칠 수 있다.

## 1. 성과 측정 장치

- **확인**: 페이지 소스에서 `gtag` / `googletagmanager` / `google-analytics` / `fbq` / `facebook.net` / `wcs.naver` 검색
- **판정**: 하나도 없음 → ✗ · 하나 이상 → ✓
- **원장님 언어**: "지난달 홈페이지에 몇 명이 왔고 몇 명이 문의했는지, 지금 확인할 방법이 있으신가요?"
- **왜 강력한가**: 원장님이 "홈페이지 효과를 모른다"고 느끼는 원인을 정확히 지목한다. 그리고 제작사가 이걸 안 심는 이유는 심으면 효과 없는 게 드러나기 때문이라는 구조적 사실을 말할 수 있다.
- **자백 연결**: "제가 만든 첫 학원 홈페이지에도 이게 없었습니다. 그래서 원장님도 저도 효과를 몰랐습니다."

## 2. 모바일 대응

- **확인**: `<meta name="viewport">` 태그 존재 여부 → 없으면 즉시 ✗. 있으면 브라우저 폭 375px에서 가로 스크롤 발생 여부
- **판정**: viewport 없음 → ✗✗ · 있으나 가로 스크롤 발생 → ✗ · 정상 → ✓
- **원장님 언어**: "휴대폰으로 열면 글씨가 작아서 손가락으로 확대해야 하거나, 화면이 좌우로 밀리지 않나요?"
- **증거**: 375px 스크린샷 1장

## 3. 모바일 문의 도달 ★ 최우선

- **확인**:
  1. 전화번호가 `<a href="tel:...">` 링크인지, 아니면 **텍스트로만** 있는지
  2. 375px 첫 화면(스크롤 0)에 연락 수단이 보이는지
  3. 안 보이면 문의처까지 스크롤 몇 번
- **판정**: `tel:` 링크 없음 → ✗✗ · 스크롤 2회 이상 → ✗ · 첫 화면 노출 + tel: 링크 → ✓
- **원장님 언어**: "휴대폰에서 전화번호를 눌렀을 때 바로 전화가 걸리시나요? 번호가 그림이나 글자로만 있으면 눌러도 아무 일도 안 일어납니다."
- **왜 최우선인가**: 학원 문의는 대부분 전화다. `tel:` 링크가 없으면 학부모가 번호를 외워서 전화앱으로 옮겨 적어야 한다. 그 단계에서 이탈한다. **매출 직결이고 원장님이 절대 모르는 항목이다.**

## 4. 로딩 속도

- **확인**: PageSpeed Insights(`pagespeed.web.dev`) **모바일** 탭. LCP 값 기록
- **판정**: LCP 2.5초 이하 → ✓ · 2.5~4초 → △ · 4초 초과 → ✗
- **원장님 언어**: "학부모가 휴대폰으로 열었을 때 화면이 뜨기까지 ○○초 걸립니다. 3초 넘으면 절반이 기다리지 않고 나갑니다."
- **왜 반박 불가인가**: 구글 공식 도구의 숫자다. 주관이 개입할 여지가 없다.
- **주의**: 회차마다 값이 흔들린다. 2회 측정해 나쁜 쪽을 쓰지 말고 **중간값**을 쓴다. 과장하면 신뢰를 잃는다.

## 5. 검색 노출

- **확인**: 네이버와 구글에서 각각
  1. `학원명` — 홈페이지가 몇 번째에 나오는가
  2. `지역 + 과목 + 학원` (예: "마포구 미술학원") — 1페이지에 누가 있는가
- **판정**: 학원명 검색으로도 1페이지에 없음 → ✗✗ · 학원명은 나오나 지역 검색에 없음 → △ · 둘 다 노출 → ✓
- **원장님 언어**: "학부모가 학원 이름으로 검색하면 원장님 홈페이지가 나오나요? 지역 검색에서는 어떤 학원들이 위에 있는지 보시겠어요?"
- **증거**: 검색 결과 스크린샷. **경쟁 학원명은 리포트에 실명으로 쓰지 않는다** — 원장님이 불편해하고, 나중에 그 학원이 고객이 될 수도 있다. "같은 지역 학원 3곳"으로 표기.

## 6. 필수 표기 (개인정보처리방침 · 사업자정보 · https)

- **확인**: 개인정보처리방침 페이지 링크 존재, 사업자등록번호 표기, `https` 여부
- **판정**: 방침 없는데 문의 폼·게시판이 있음 → ✗ · https 아님 → ✗✗
- **원장님 언어**: "문의 게시판으로 학부모 이름이나 연락처를 받고 계신데, 개인정보처리방침 페이지가 없습니다. 개인정보보호법에 처리방침을 정해서 공개하도록 되어 있습니다."
- **말하지 말 것**: **과태료 금액**. 틀린 숫자 하나로 신뢰가 날아간다. "규정이 있다"까지만.
- **선 긋기**: "법적으로 문제없게 만들어드립니다"(✗) / "표준 양식 기준으로 초안을 만들고, 최종 확인은 원장님이 하십니다"(✓). 방침의 법적 책임자는 개인정보처리자인 원장님이다.

## 부가 관찰 (자유, 최대 2개)

6항목 밖에서 눈에 걸리는 것 1~2개만. 예: 푸터 카피라이트가 `2001~2022`(문 닫은 줄 안다), 강사 사진 깨짐, 공지 마지막 글이 2년 전.

3개 이상 쓰지 않는다. 지적이 많아지면 리포트가 비난처럼 읽히고 방어 반응을 부른다.

# Type A — 검색 노출 진단 4항목 (홈페이지 없는 24곳)

홈페이지가 없으면 진단할 사이트가 없다. 대신 **학부모가 검색했을 때 무엇을 보는가**를 보여준다.

핵심 메시지 한 줄:

> 학부모가 원장님 학원을 검색하면, 원장님이 손댈 수 없는 남의 페이지를 봅니다.

## A1. 학원명 검색 결과

- **확인**: 네이버·구글에 `학원명` 검색. 1페이지에 무엇이 있는가
- **기록**: 3자 디렉토리(모든학원 등) 몇 건 / 원장님이 직접 관리하는 채널(플레이스·블로그·인스타) 몇 건 / 경쟁 학원 광고 유무
- **원장님 언어**: "학부모가 학원 이름을 검색하면 나오는 게 ○○사이트인데, 원장님이 내용을 고칠 수 없는 곳입니다."

## A2. 지역+과목 검색 1페이지

- **확인**: `지역 + 과목 + 학원` 검색. 1페이지 구성
- **기록**: 자체 홈페이지를 가진 학원이 몇 곳인가
- **원장님 언어**: "이 검색에서 위에 올라온 학원 ○곳은 자기 홈페이지가 있습니다. 원장님은 이 목록에 없습니다."
- **경쟁 학원명은 실명으로 쓰지 않는다.**

## A3. 학부모가 얻을 수 있는 정보의 양

- **확인**: 검색으로 도달 가능한 페이지에서 얻을 수 있는 정보를 목록화
- **기록**: 보통 전화·주소·수강료까지만 나오고, **강사 이력 / 커리큘럼 / 합격 실적 / 시설 사진**이 없다
- **원장님 언어**: "학부모가 상담 전화를 걸기 전에 확인하고 싶은 건 강사와 실적입니다. 지금은 그걸 볼 방법이 없어서, 전화까지 오는 학부모가 줄어듭니다."
- **왜 강력한가**: 홈페이지의 진짜 역할이 유입이 아니라 **검증**이라는 것을 원장님 언어로 설명한다. 그리고 이게 사실이다.

## A4. 연락까지의 단계

- **확인**: 검색 결과에서 전화 걸기까지 몇 번의 이동이 필요한가
- **기록**: 검색 → 디렉토리 진입 → 번호 확인 → 전화앱 전환 = 4단계
- **원장님 언어**: "지금은 전화까지 4단계입니다. 홈페이지가 있으면 1단계입니다."

# 작성 절차 — Type B 60분 체크리스트

순서대로 하면 60분에 끝난다. 순서를 바꾸면 문서 작성 시간이 부족해진다.

| # | 작업 | 시간 | 산출 |
|---|---|---|---|
| 1 | 소스 확인 — 측정 장치, viewport, `tel:` 링크, 방침 링크, https | 5분 | 1·2·3·6번 1차 판정 |
| 2 | PageSpeed Insights 모바일 2회 | 5분 | 4번 LCP 중간값 |
| 3 | 375px 폭에서 첫 화면 + 문의 도달 확인, 스크린샷 | 10분 | 2·3번 확정, 증거 1장 |
| 4 | 네이버·구글 검색 4건, 스크린샷 | 10분 | 5번 확정, 증거 1장 |
| 5 | 부가 관찰 훑기 | 5분 | 최대 2개 |
| 6 | 템플릿에 채워 쓰기 | 20분 | 리포트 |
| 7 | PDF 변환 + 이미지 1장 추출 | 5분 | 전달본 |

**자동화 지렛대**: 1번 항목(소스 확인)은 27곳을 한 번에 돌리는 스크립트로 대체 가능하다. 그러면 곳당 5분이 사라지고 판정이 일관된다. 대표가 개발자라서 쓸 수 있는 무기이고, 진단 3~4건을 손으로 해본 뒤에 만드는 게 맞다 — 먼저 만들면 무엇을 자동화해야 하는지 모른 채로 만든다.

## 전달 형식

PLAN.md의 배포 방침에 따라 **PDF + 이미지 1장**. 카톡·문자로 바로 넘길 수 있어야 한다.

- 이미지 1장은 리포트 1페이지(요약)만 캡처한 것. 카톡 미리보기에서 내용이 보여야 열린다.
- 파일명: `{학원명}-홈페이지진단-YYYYMMDD.pdf`

## 리포트에 반드시 있어야 하는 것

1. **날짜와 작성자** — 언제 기준인지 없으면 신뢰가 안 생긴다
2. **판정 근거 수치** — "느립니다"가 아니라 "LCP 4.2초(권장 2.5초 이하)"
3. **조치와 티어 연결** — 각 항목이 어느 티어에 포함되는지. 이게 견적의 근거가 된다
4. **무료임을 명시** — "이 진단은 무료이며, 진단만 받고 진행하지 않으셔도 됩니다." 부담을 없애야 열어본다

## 하지 말 것

- 6항목 밖으로 지적을 늘리는 것 — 리포트가 비난이 된다
- 디자인 취향 지적("촌스럽다", "요즘 스타일이 아니다") — 주관이고 반박당한다
- 경쟁 학원 실명 — 원장님이 불편해하고, 그 학원이 나중에 고객일 수 있다
- 과태료 금액, "법적으로 문제없게" 류의 표현
- 진단 단계에서 고쳐주기 — 무상 제작의 시작점
