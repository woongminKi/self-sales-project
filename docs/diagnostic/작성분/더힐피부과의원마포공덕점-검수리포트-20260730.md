## 1. 홈페이지 화면에 오류 메시지가 나오고 있습니다

첫 화면 맨 아래쪽에 이런 내용이 그대로 표시됩니다.

```
mysqli_result Object ( [current_field] => 0 [field_count] => 18
[lengths] => [num_rows] => 5 [type] => 0 )
```

홈페이지가 데이터를 불러오는 과정에서 생긴 오류 메시지가 **감춰지지 않고 방문자 화면에 출력되는 상태**입니다. 환자분들도 보고 계십니다.

두 가지가 문제입니다.

- 관리되지 않는 홈페이지라는 인상을 줍니다
- 내부 데이터 구조 정보(항목 수, 건수)가 함께 드러납니다

**확인 방법**: `thehealmapo.com` 첫 화면에서 맨 아래로 스크롤

**조치**: 오류 출력을 끄고, 오류가 난 원인(데이터 조회 부분)을 함께 수정합니다.

## 2. 휴대폰에서 전화번호를 눌러도 전화가 걸리지 않습니다

홈페이지의 `02-707-1020` 이 **눌러서 전화를 걸 수 있는 형태가 아니라 글자로만** 표시되어 있습니다.

환자분이 전화하려면 번호를 외우거나 옮겨 적어서 전화 앱에 직접 입력해야 합니다. **이 단계에서 상당수가 그냥 나갑니다.**

피부과 상담은 대부분 전화로 들어옵니다. 홈페이지에서 발생하는 손실 중 가장 직접적인 부분입니다.

**확인 방법**: 휴대폰으로 홈페이지를 열어 전화번호를 눌러보시면 아무 일도 일어나지 않습니다.

**조치**: 번호를 누르면 바로 통화 화면이 뜨도록 변경하고, 어느 페이지에서나 보이는 문의 버튼을 고정합니다.

## 3. 휴대폰 화면에 맞춰지지 않습니다

홈페이지에 **화면 크기 설정(viewport)이 없습니다.** 그래서 휴대폰이 PC 화면을 그대로 축소해 보여줍니다.

- 글씨가 작아서 손가락으로 확대해야 읽힙니다
- 화면이 좌우로 밀립니다 (가로 스크롤 발생)

**확인 방법**: 휴대폰으로 홈페이지를 열고 좌우로 밀어 보시면 화면이 옆으로 움직입니다.

**조치**: 휴대폰 화면 기준으로 레이아웃을 재구성합니다.

## 4. 보안 연결(https)이 설정되어 있지 않습니다

`https://thehealmapo.com` 으로 접속하면 **보안 인증서가 도메인과 맞지 않아** 경고가 표시됩니다. 현재는 `http://` 로만 정상 접속됩니다.

호스팅 업체(가비아)의 공용 인증서가 응답하고 있어, 더힐피부과 도메인 전용 인증서가 설치되지 않은 상태로 보입니다.

브라우저는 `http://` 사이트의 주소창에 **"안전하지 않음"** 을 표시합니다. 병원 홈페이지에서는 신뢰에 영향이 있습니다.

**확인 방법**: 주소창에 `https://thehealmapo.com` 을 직접 입력해 보시면 경고가 뜹니다.

**조치**: 도메인 인증서를 발급받아 설치하고, `http` 접속을 `https` 로 자동 전환합니다. 무료 인증서로도 가능합니다.

## 5. 비급여 진료비용 고지 페이지가 확인되지 않습니다

시술 소개 페이지는 20개 이상 갖춰져 있는데(리프팅, 보톡스, 필러, 색소 등), **비급여 진료비용을 안내하는 페이지가 홈페이지에서 확인되지 않습니다.**

의료법 제45조는 의료기관이 비급여 진료비용을 환자가 쉽게 알 수 있도록 고지하도록 정하고 있습니다. 같은 지역 피부과 중에는 홈페이지에 "비급여수가" 메뉴를 두고 있는 곳이 있습니다.

원내에 게시하고 계실 수 있으니, **홈페이지 게시 여부만 한 번 확인해 보시길 권합니다.**

**조치**: 비급여 항목·금액 페이지를 만들고, 원장님이 직접 수정할 수 있게 관리 화면을 붙입니다. (피부과는 항목이 자주 바뀌어서 이 부분이 실사용 빈도가 높습니다)

## 6. 개인정보처리방침 내용이 실제와 맞지 않습니다

방침 페이지에 수집 항목이 이렇게 적혀 있습니다.

> 이름, 생년월일, 성별, **로그인ID, 비밀번호**, 자택 전화번호, 휴대전화번호, 이메일, **14세미만 가입자의 경우 법정대리인의 정보**

그런데 지금 홈페이지에는 **회원가입 기능이 없습니다.** 다른 업종용 범용 양식이 그대로 들어간 것으로 보입니다.

방침은 실제 처리 실태를 반영해야 하므로, 실제로 받는 정보에 맞게 정리하는 것이 좋습니다.

**조치**: 실제 수집 항목에 맞게 방침을 다시 작성합니다. 표준 양식을 기준으로 초안을 만들어 드리고, **내용 최종 확인은 원장님이 하십니다** — 방침의 책임자는 의료기관이기 때문입니다.

## 7. 의료법 제56조 관련해 확인이 필요해 보이는 문구

**위반이라고 말씀드리는 것이 아닙니다.** 제56조 금지광고 기준은 사안별로 판단이 갈리는 부분이 많고, 최종 판단은 심의기관이나 법률 자문의 영역입니다. 아래는 **한 번 점검해 보시길 권하는 문구**입니다.

| 문구 | 확인이 필요한 이유 |
|---|---|
| **"대한민국 2% 피부과전문의 진료"** | 「2%」라는 수치의 산출 근거를 제시할 수 있는지. 객관적 근거 없는 수치는 과장 광고로 볼 여지가 있습니다 |
| "최고급 장비를 사용합니다" | 최상급 표현 |
| "어디에서도 경험할 수 없었던 공간과 서비스" | 최상급·비교 표현 |
| "만족도 높은 결과를 이끌어냅니다" | 치료 효과에 관한 표현 |

참고로 **의원 자체 홈페이지는 사전심의 대상이 아닙니다.** (사전심의는 일일 평균 이용자 10만 명 이상인 매체나 신문·옥외광고 등이 대상입니다.) 다만 제56조 금지광고 기준은 **매체와 무관하게 적용**되므로 홈페이지 문구도 대상입니다.

- **사업자등록번호·대표자·주소·전화가 푸터에 모두 표기**되어 있습니다.

**콘텐츠는 이미 있습니다.** 새로 만들 것보다 지금 있는 것을 제대로 보이게 하는 작업이 대부분입니다.

## 개선하면 볼 수 있게 되는 숫자

지금은 홈페이지에 성과를 측정하는 장치가 없어서, 방문자 수나 문의 건수를 확인할 방법이 없습니다. 작업 시 기본으로 넣고 **매달 정리해서 보내드립니다.**

- 홈페이지 방문자 수
- 그중 전화·카카오톡으로 이어진 비율
- 방문자가 어디서 왔는지 (검색 / 인스타 / 블로그 / 직접)
- **문의하려다 실패한 건수**

**효과가 없으면 없다고 보고드립니다.** 숫자를 심는 이유가 그것입니다.

> 솔직히 말씀드리면, 제가 처음 만든 홈페이지에는 이 장치를 넣지 않았습니다. 그래서 사이트는 새로 됐는데 효과가 있었는지 저도 의뢰인도 몰랐습니다. 지금은 그렇게 하지 않습니다.
