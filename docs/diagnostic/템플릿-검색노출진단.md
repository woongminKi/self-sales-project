## 3. 학부모가 지금 얻을 수 있는 정보

검색으로 도달 가능한 페이지에서 확인되는 정보입니다.

| | 확인 가능 |
|---|---|
| 전화번호 · 주소 | {{○}} |
| 과목 · 수강료 | {{○ (다만 등록 시점 기준)}} |
| **강사 이력** | **✗** |
| **커리큘럼** | **✗** |
| **합격·성적 실적** | **✗** |
| **시설 사진** | **✗** |

학부모가 상담 전화를 걸기 전에 확인하고 싶은 것은 **누가 가르치는지, 결과가 어땠는지**입니다. 지금은 그걸 볼 방법이 없습니다.

홈페이지는 학부모를 새로 데려오는 곳이 아닙니다. **이미 학원 이름을 들은 학부모가 "여기 보낼 만한가"를 확인하러 오는 곳**입니다. 그 확인 절차가 지금 비어 있어서, 전화까지 도달하는 학부모가 줄어듭니다.

## 4. 전화까지 몇 단계인가

현재:

```
검색  →  디렉토리 페이지 진입  →  번호 확인  →  전화앱으로 옮겨 입력  →  통화
```

{{4}}단계입니다. 홈페이지가 있으면:

```
검색  →  홈페이지에서 전화 버튼 누름  →  통화
```

{{2}}단계로 줄어듭니다.

## 만들면 볼 수 있게 되는 숫자

홈페이지에는 성과 측정 장치를 기본으로 넣습니다. 그래서 다음 달부터 이 숫자를 매달 보내드립니다.

- 홈페이지 방문자 수
- 그중 전화·문의로 이어진 비율
- 방문자가 어느 경로에서 왔는지 (검색 / 인스타 / 직접)

**효과가 없으면 없다고 보고드립니다.** 숫자를 심는 이유가 그것입니다.

> 제가 처음 만든 학원 홈페이지에는 이 장치를 넣지 않았습니다. 그래서 사이트는 새로 됐는데 효과가 있었는지 원장님도 저도 몰랐습니다. 지금은 그렇게 하지 않습니다.
