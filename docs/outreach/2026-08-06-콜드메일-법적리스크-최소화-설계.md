# 콜드 메일 — 법적 리스크 최소화 설계

작성일: 2026-08-06 · 대상: 2군 이메일 확보분
상태: **미발송**

## 전제 (기록)

KISA에 문의했으나 **명확한 답변을 받지 못했다.** 대표 판단으로 발송을 진행하되, 문제가 생기면 그때 대응한다는 방침이다. 이 문서는 그 전제 위에서 **실제로 리스크를 낮추는 구성**을 정리한 것이며, 법률 자문이 아니다.

관련 조항:
- 정보통신망법 **제50조** — 영리목적 광고성 정보 전송 시 사전 동의(옵트인), 제4항 표기 의무, 제5항 야간 전송 제한
- 정보통신망법 **제50조의2** — 프로그램·기술적 장치를 이용한 이메일 주소 무단 수집 금지
- 개인정보보호법 **제20조** — 정보주체 이외로부터 수집한 개인정보의 수집 출처 고지

---

## 핵심 전략 — "광고성 정보"에 해당하지 않게 만든다

제50조는 **영리목적의 광고성 정보**에 적용된다. 자신이 판매하는 재화·서비스에 관한 정보가 전혀 없으면 광고성 정보로 보기 어렵다.

그래서 **1차 메일에서 아래를 전부 뺀다.**

| 빼는 것 | 이유 |
|---|---|
| 가격 (180/380/680) | 재화·서비스 정보 = 광고성의 핵심 징표 |
| 포트폴리오·데모 링크 | 자기 홍보 |
| "제작해 드립니다" 류 제안 | 청약 유인 |
| 회사 소개·강점 | 홍보 문구 |

**남기는 것은 "당신 사이트에 이런 문제가 있다"는 사실 전달뿐이다.** 회신이 오면 그때부터는 상대가 먼저 문의한 것이므로 제안을 자유롭게 할 수 있다.

이 구조는 법적으로 안전할 뿐 아니라 **심리적으로도 더 강하다.** 파는 사람이 아니라 알려주는 사람이 된다.

## 대안 — (광고) 표기형

무광고형이 "그래도 궁극적으로 영업 목적이니 광고성"으로 해석될 여지를 완전히 없애려면, **제목 맨 앞에 `(광고)` 를 붙이고 제안 내용을 넣는 방식**도 있다.

> **제목:** (광고) {{의원명}} 홈페이지 보안 연결 오류 안내

**트레이드오프**

| | 무광고형 | (광고) 표기형 |
|---|---|---|
| 제50조 표기 의무 | 광고성이 아니라는 전제 — 판정이 뒤집히면 위반 | 확실히 준수 |
| 열람률 | 높음 | **크게 떨어짐** — (광고) 메일은 대부분 안 열린다 |
| 제안 포함 | 불가 (회신 후 2차에서) | 가능 |

**권장은 무광고형이다.** 1차 목적이 수주가 아니라 대화를 여는 것이고, (광고) 표기를 달면 열람률이 무너져 발송 자체가 무의미해진다. 다만 이건 판단이지 보증이 아니다.

## 2차 메일 — 회신이 왔을 때

회신은 **상대가 먼저 연락한 것**이므로 제50조 이슈가 사라진다. 여기서부터 제안한다.

1. 지적한 내용의 **구체적 재현 방법**을 다시 알려준다
2. **무료 점검 리포트**를 제안한다 (`docs/diagnostic/템플릿-홈페이지진단.md`, 더힐 리포트가 실물 예시)
3. 견적은 **묻기 전에 먼저 꺼내지 않는다.** 물으면 180 / 380 / 680, 유지보수 월 8만·15만
4. 사이트 링크(`self-sales-project.vercel.app`, `/demo/clinic`)는 이 단계에서 처음 보낸다

## 운영 규칙

### 발송 경로 — Resend를 쓰면 안 된다

**Resend는 트랜잭셔널 전용 서비스다.** 콜드 아웃리치에 쓰면 계정이 정지되고, 그러면 **홈페이지 문의 폼 수신도 함께 멈춘다.** 문의 폼과 콜드 발송은 반드시 분리한다.

| 경로 | 판단 |
|---|---|
| Resend | ❌ 계정 정지 → 문의 폼 동반 사망 |
| Gmail 수동 발송 | ⭕ 권장. 단 **하루 20~30통 이하** (일일 한도·스팸 판정 회피) |
| 별도 도메인 + 전용 발송 서비스 | 향후 볼륨이 커지면 검토. 도메인 평판을 gmail과 분리 |

### 발송량·시간

- **하루 20~30통 이하.** 대량 발송은 스팸 필터와 신고 리스크를 동시에 키운다
- **08:00~21:00 발송** (제50조 제5항). 병원은 야간에 어차피 안 본다
- 1곳 1회. 회신 없으면 종료

### 수신거부 처리 (분쟁 시 가장 중요한 증빙)

1. "수신거부" 회신이 오면 **즉시** `form-messages.csv`의 해당 행에 기록하고 발송 목록에서 제외
2. 처리 사실을 **1회 회신**으로 알린다 — "요청하신 대로 발송 목록에서 삭제했습니다. 다시 연락드리지 않겠습니다."
3. 그 뒤로는 어떤 이유로도 재발송하지 않는다

### 발송 기록 보관

`docs/leads/form-messages.csv`에 발송일·경로·회신·수신거부 여부를 남긴다. **분쟁이 생기면 이 기록이 유일한 방어 근거다.** 무엇을 언제 누구에게 보냈고, 반복 발송이 없었으며, 수신거부를 즉시 처리했다는 것을 보여줄 수 있어야 한다.

## 문제가 생겼을 때

| 상황 | 대응 |
|---|---|
| 수신거부 요청 | 즉시 처리 + 1회 회신 + 기록. 논쟁하지 않는다 |
| "왜 내 주소를 알았냐" 항의 | "귀 기관 홈페이지에 공개 게시된 주소로 연락드렸습니다"라고 사실대로 답하고 삭제 처리 |
| KISA·기관 문의 접수 통보 | 발송 기록 전체를 제출한다. 은폐·삭제하지 않는다 |
| Gmail 계정 경고 | **즉시 발송 중단.** 문의 폼 수신 계정과 같으므로 사업 자체가 멈춘다 |

**중단 기준을 미리 정해둔다**: 수신거부 요청이 발송량의 5%를 넘거나, 기관 문의가 1건이라도 접수되면 발송을 멈추고 구성을 재검토한다.

## 미해결

- **KISA 유권해석 미확보.** 재문의하거나, 서면(`spam.kisa.or.kr` 상담 게시판)으로 남겨 답변을 문서로 받아두는 것을 권한다. 서면 답변은 그 자체가 방어 근거가 된다
- **전화권유판매 신고 의무** — 관할 구청 지역경제과. 1군 62곳 전화 채널이 여기 걸려 있다
