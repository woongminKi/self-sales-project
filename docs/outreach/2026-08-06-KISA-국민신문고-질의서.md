# KISA 질의서 (국민신문고 접수용)

작성일: 2026-08-06 · 상태: **미접수**

## 접수 경로

KISA 불법스팸대응센터의 **「고객광장 > 문의하기」 기능은 2024-03-22 종료**됐다. 현재 경로는 셋이다.

| 경로 | 답변 형태 | 판단 |
|---|---|---|
| **국민신문고** `epeople.go.kr` | 공식 서면 회신, 법정 처리기한 | **권장** — 기록이 남아 방어 근거가 된다 |
| `helpspam@kisa.or.kr` | 이메일 회신 | 간편하나 회신·기한 보장 없음 |
| 전화 `118` | 구두 | 기록이 안 남는다 |

**국민신문고 접수 방법**
1. `epeople.go.kr` 접속 → 민원신청 (공동인증서·간편인증 필요)
2. 처리기관: **한국인터넷진흥원(KISA)** 지정
3. 민원 유형: 질의·상담
4. 제목·내용에 아래 문안을 그대로 붙여넣는다

**답변이 오면 반드시 저장한다.** 이 문서 하단 「접수 기록」에 접수번호·접수일·답변 요지를 남긴다.

## 본문 (그대로 붙여넣기)

```
안녕하세요.

홈페이지 제작업을 하는 1인 사업자입니다. 의료기관(의원) 홈페이지의 기술적 결함을
알려드리는 메일을 발송하려 하는데, 정보통신망법 제50조 및 제50조의2 적용 여부가
불분명하여 질의드립니다.

■ 사실관계

1. 수집 대상
   - 건강보험심사평가원이 공공누리(출처표시) 조건으로 공개한 「전국 병의원 및 약국
     현황」 파일에 포함된 요양기관 정보를 이용했습니다.
   - 위 파일에는 각 의료기관이 신고한 홈페이지 주소가 포함되어 있습니다.
   - 이메일 주소는 위 파일에 없으며, 각 의료기관 홈페이지에 공개 게시된 대표 이메일을
     별도로 확인했습니다.

2. 이메일 주소 확인 방법
   - 각 홈페이지의 하단(푸터), 개인정보처리방침 페이지, 문의 안내 페이지를 사람이
     브라우저로 직접 열어 화면에 게시된 주소를 확인했습니다.
   - 확인 과정에서 페이지 본문에 대한 정규표현식 검색을 1차 보조 수단으로 사용했고,
     그 결과를 사람이 원본 페이지에서 다시 확인한 뒤에만 사용합니다.
   - 검색 결과에만 나오고 원본 페이지에서 확인되지 않은 주소는 사용하지 않습니다.
   - 개인 휴대전화번호나 비공개 정보는 수집하지 않았습니다.

3. 발송하려는 메일의 내용
   - 수신 기관 홈페이지에서 확인된 기술적 결함(예: https 접속 시 보안 인증서 오류로
     경고 화면 표시, 전화번호가 클릭 통화 형식이 아님)을 알리는 내용입니다.
   - 해당 결함의 확인 방법과 일반적인 해결 방법을 함께 적습니다.
   - 제가 제공하는 서비스의 명칭·가격·홈페이지 주소·포트폴리오 등 홍보성 내용은
     일절 포함하지 않습니다. 제작 의뢰를 권유하는 문구도 넣지 않습니다.
   - 본문에 ① 해당 기관 홈페이지에 공개된 주소로 발송했다는 수집 출처, ② 발신자
     실명과 연락처, ③ 수신거부 방법, ④ 회신 여부와 무관하게 재발송하지 않는다는
     내용을 명시합니다.
   - 1개 기관당 1회만 발송하며, 08시~21시 사이에만 발송합니다.

■ 질의사항

1. 위 3항과 같이 자신이 판매하는 재화·서비스에 관한 내용을 일절 포함하지 않고,
   수신자 홈페이지의 기술적 결함 사실만을 알리는 메일이 정보통신망법 제50조 제1항의
   "영리목적의 광고성 정보"에 해당합니까?

2. 만약 해당한다면, 제목에 "(광고)" 표기를 하고 제50조 제4항의 표시사항(전송자 명칭·
   연락처, 수신거부 방법)을 모두 기재하는 것으로 적법한 전송이 됩니까? 아니면
   그와 별개로 수신자의 사전 동의를 반드시 받아야 합니까?

3. 수신자가 개인이 아니라 사업자(의료기관)이고, 수집한 주소가 그 사업자가 홈페이지에
   공개 게시한 대표 이메일인 경우에도 제50조 제1항의 사전 동의 의무가 동일하게
   적용됩니까?

4. 위 2항과 같이 사람이 브라우저로 원본 페이지를 직접 열어 확인하되 정규표현식 검색을
   1차 보조 수단으로 사용한 방식이, 제50조의2가 금지하는 "프로그램 그 밖의 기술적
   장치를 이용한 전자우편주소 수집"에 해당합니까? 만약 해당한다면, 어떤 방식까지가
   허용되는 확인 방법인지 알려주시면 감사하겠습니다.

5. 수신거부 요청을 받은 경우 처리 사실을 회신으로 알리고 발송 목록에서 삭제하는 것
   외에, 사업자가 별도로 보관해야 하는 증빙이나 이행해야 하는 절차가 있습니까?

바쁘신 중에 감사합니다. 답변 주시면 그에 맞추어 발송 여부와 방식을 정하겠습니다.
```

## 이 문안이 이렇게 쓰인 이유

지난 문의에서 확답을 받지 못한 원인은 질문이 추상적이었기 때문으로 본다. 담당자가 사실관계를 특정할 수 없으면 "사안에 따라 다르다"는 답이 나온다.

| 설계 | 의도 |
|---|---|
| 수집·발송 방법을 **동작 단위로** 서술 | 담당자가 그대로 판단할 수 있게 한다 |
| 질의를 5개로 **분리** | 하나씩 답할 수 있게 한다. 뭉치면 뭉뚱그려진 답이 온다 |
| 질의 2를 "만약 해당한다면"으로 조건화 | 1번이 부정이어도 대비책을 함께 받는다 |
| 질의 3에서 **사업자 수신자**를 명시 | 개인 대상 스팸과 B2B를 구분해 답하게 한다 |
| 질의 4에 **정규표현식 사용 사실을 자진 기재** | 숨기면 답이 무의미해진다. 그리고 은폐하지 않았다는 기록이 남는다 |
| 홍보성 내용 미포함을 **구체적으로 열거** | 제50조의 "광고성" 판단에 직결되는 핵심 사실이다 |

**불리할 수 있는 사실(정규표현식 사용)을 그대로 적었다.** 유리하게만 쓰면 답변을 받아도 실제 행위와 달라 방어 근거가 되지 못한다.
