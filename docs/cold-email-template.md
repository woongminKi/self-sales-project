# 콜드 메일 템플릿 (학원 원장용 v1)

> 원칙: 대량 광고문이 아니라 **"그 학원 홈페이지를 실제로 보고 쓴 1:1 제안서"**. 개인화 슬롯 3개를 채우지 못하면 그 리드에게는 보내지 않는다.

## 발송 원칙 (준법 + 전환율)

1. **1통 = 1학원.** 동일 문안 대량 발송 금지. BCC 발송 금지.
2. 수신처는 **공개된 사업장 이메일**(홈페이지·네이버 플레이스에 게시된 주소)만.
3. 하단에 **수신거부 문구 필수**, 거부 의사 수신 즉시 리스트 제외 후 스프레드시트에 기록.
4. `(광고)` 표기: 순수 광고성이면 제목 앞에 필수. 아래 템플릿처럼 **특정 문제 지적 + 개별 제안** 형태면 통상 정보성·제안성으로 보지만, 회색지대이므로 **KISA 문의(PLAN.md Week 2) 항목에 이메일 포함**해 확인 전까지는 보수적으로 `(광고)` 표기를 붙인다.
5. 발송 시간 평일 09~18시. 팔로업은 **1회만**, 5~7일 후.
6. 개인화 슬롯 조사에 리드당 10분 상한 — 홈페이지 접속 1회 + 네이버 플레이스 1회면 충분.

## 제목 (A/B — 30곳 단위로 평가)

- A안: `(광고) {학원명} 홈페이지, 모바일에서 상담 버튼이 안 보입니다`
- B안: `(광고) {학원명} 원장님께 — 9월 신학기 전 홈페이지 리뉴얼 제안`

```

바쁘실 것 같아 짧게만 — 말씀드린 {개인화 슬롯 1 요약}은
학부모 입장에서 등록 문의를 포기하게 되는 대표적인 지점이라
한 번은 꼭 확인해보시길 권해드립니다.

무료 진단 제안은 이번 주까지 유효합니다. 회신 한 줄이면 됩니다.
```

## 전환 설계 (메일 → 홈페이지 → 견적 문의)

- 메일의 링크는 **포트폴리오 홈페이지 1개만** (선택지를 늘리지 않는다).
- 홈페이지에서 할 일: 사례 확인 → 가격대 확인 → 견적 문의 폼 제출. 폼 제출이 이 퍼널의 전환 지점.
- 스프레드시트 기록: 학원명 / 발송일 / 제목 버전 / 개인화 슬롯 내용 / 응답 여부 / 다음 액션 / (동의·거부 기록).

## 30곳 단위 평가 기준 (PLAN.md 퍼널 임계값과 동일)

- 응답률(회신+폼 제출) < 10% → 제목·첫 문단 교체
- 응답 → 미팅 전환 < 30% → 제안(무료 진단) 교체
