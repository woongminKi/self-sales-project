**채널은 우선순위별로 갈라야 한다.** A등급 24곳은 홈페이지가 없으니 공개 이메일도 없다 — 여기에 콜드 이메일을 쓸 방법은 존재하지 않는다.
- **A등급 24곳** → 전화 또는 방문 전용
- **B·C등급 27곳** → 콜드 이메일. 이 중 **20곳은 주소 확보 완료(74%)**

즉 이메일 확보율 39%는 리스트의 약점이 아니라 A등급 비중이 높다는 뜻이고, **이메일이 있을 수 있는 모집단(B·C) 안에서는 74%를 확보했다.**

## 수집 방법

### 1차 소스: 모든학원(allhakwon.com)
네이버 지도/플레이스는 접근이 차단됐다(`m.place.naver.com` HTTP 429 과다요청 제한, `map.naver.com` 검색 API HTTP 403). 그래서 **교육청 학원·교습소 등록 정보를 재공개하는 디렉토리인 모든학원**을 1차 소스로 사용했다.

- 행정구별 목록: `https://allhakwon.com/area/{법정동코드}` (마포구 1144 / 서초구 1165 / 강남구 1168), 페이지당 51건 × 5페이지 = 구별 약 250건 수집
- 상세 페이지: `https://allhakwon.com/academy/{id}` — **공개 전화번호, 주소, 과목별 정원, 수강료**를 제공. 전화번호는 전부 여기서 확보

### 후보 선별 기준 (약 250건 → 구별 28건)
1. 명칭이 `학원`으로 끝나는 곳만 (교습소·개인과외 제외)
2. 대상 업종 키워드 포함: 영어·수학·국어·어학·입시·보습·종합·논술·과학·미술·음악·연기·무용·디자인
3. 제외 업종: 간호조무사·세무회계·공무원·부동산·미용·조리·운전 등 성인 직업교육
4. **규모 프록시 = 주소에 표기된 층수** — `2,3,4층`, `1층~5층`, `3층 전체` 처럼 복수 층·전층을 쓰는 곳을 상위로 정렬. 등록 정보에 연면적·강사수가 없어 층수를 대리 지표로 썼다
5. 전국 프랜차이즈 지점(정상어학원·청담어학원·SLP·크라센·게이트·파고다·종로·메가·눈높이·해법 등)은 제외 — 홈페이지가 본사 관리라 리뉴얼 결정권이 원장에게 없음

### 2차 확인: 홈페이지·이메일
- 학원명으로 웹 검색 → 자체 홈페이지 존재 여부 판정
- 홈페이지가 있으면 **실제 Chromium 헤드리스 브라우저로 직접 접속**해서 다음을 추출:
  - `<meta name="viewport">` 태그 유무 → 모바일 대응 여부의 객관적 지표
  - 푸터 카피라이트 연도, 최신 공지 날짜 → 방치 기간
  - HTML 전체 정규식 매칭으로 이메일 주소
- 이메일이 첫 페이지에 없으면 **개인정보처리방침·이용약관·문의 페이지를 따로 열어 확인** — 한국 사이트는 이메일을 개인정보처리방침에만 적어두는 경우가 많다. 산에듀(jeonghee.han@sanedu.com), SJA실용음악학원(master6265@sja.co.kr), 그룹티아이연기학원(groupti@naver.com)이 이 경로로만 확보됐다

### 3차: 이메일 보강 수집
1차 결과가 이메일 7건에 그쳐, **홈페이지를 가진 학원만 노리는 2차 수집**을 따로 돌렸다. 등록 목록에서 아직 안 쓴 후보를 층수 기준으로 다시 추린 뒤, 정적 페치가 403·인증서 오류로 못 읽은 사이트를 **전부 실브라우저로 재방문**했다. 여기서 13건이 추가돼 최종 20건이 됐다.

교훈 하나: **"이메일 없음" 판정의 상당수가 도구의 한계였지 사실이 아니었다.** 재수집 대상은 새 학원이 아니라 이미 "없음"으로 판정했던 사이트들이었고, 그중 5곳에서 이메일이 나왔다.

## 데이터 신뢰성

**전화번호**: 51건 전부 등록 정보 또는 학원 자체 홈페이지 푸터에서 추출. 이 중 10건(굿모닝미술·뉴탑보습·윤정영어·뉴오투미술·대치이화무용·새말논술·매쓰큐보습·도화2관미술·베블렌수학·그룹티아이연기)을 브라우저로 원본 페이지를 다시 열어 대조했고 **10건 전부 정확히 일치**했다.

**이메일**: 20건 전부 실제 브라우저로 해당 페이지를 열어 화면에 게시된 것을 확인했다. 검색 결과에만 나오고 원본 페이지에서 확인되지 않은 주소는 **전부 버렸다**.

**수집 범위**: 공개된 사업장 대표번호와 홈페이지에 게시된 대표 이메일만 담았다. 개인 휴대폰 번호나 비공개 정보는 수집하지 않았다. 아트폴미술학원처럼 사이트에 휴대폰번호가 함께 적힌 경우에도 대표번호만 취했다.

### 정적 페치의 오탐 — 실브라우저 검증이 필수였던 이유
조사 도구를 두 가지(정적 HTML 페치 / 실제 Chromium) 병행했는데, **정적 페치 결과를 그대로 믿었다면 리스트의 상당 부분이 틀렸다.**

- **SSL 오탐**: 1차 조사에서 마포 5개 사이트가 "SSL 인증서 오류로 방치 추정"으로 보고됐으나, 브라우저로 열어보니 `willmath.com`·`newmusicac.com`·`omf.kr`은 정상 로드됐다. 도구의 TLS 처리 문제였지 사이트 결함이 아니었다. (반대로 `yjactors.com`은 Chromium에서도 `ERR_CERT_AUTHORITY_INVALID`가 재현돼 진짜 결함으로 확정)
- **403 차단 오탐**: 정적 페치가 403으로 튕긴 사이트 다수가 브라우저에서는 정상 열렸고, **여기서만 이메일 5건**을 추가로 건졌다(design-soul.com, artfol.net, designslove.co.kr, iammusic.co.kr, 그리고 개인정보처리방침 경유 sja-musicedu.com). `iammusic.co.kr`은 정적 조사에서 "개인정보처리방침까지 읽었으나 이메일 없음"으로 판정됐던 곳인데 브라우저에서는 바로 나왔다
- **이메일 오독 정정**: 베블렌수학학원의 주소가 검색 결과 기반으로 `veblenacademy@naver.com`으로 보고됐으나, 실제 사이트 푸터에는 `veblenmath@naver.com`이었다. 잘못된 쪽으로 발송했으면 반송됐을 것

## 한계 (그대로 알고 써야 할 것)

1. **"홈페이지 없음"은 부정 증명이다.** 검색에 안 잡혔다는 뜻이지 존재하지 않는다는 증명은 아니다. 검색 노출이 약한 자체 사이트가 있을 수 있다 — 접촉 전 통화에서 한 번 확인할 것
2. **A등급 24곳에는 콜드 이메일을 쓸 수 없다.** 홈페이지가 없으니 공개 이메일도 없고, 더 파도 나오지 않는다. 이 24곳은 전화·방문 채널로 분리해 운영할 것
3. **업종이 한쪽으로 쏠렸다.** 이메일이 확보된 20곳 중 다수가 미술·실용음악·연기 학원이다. 예체능 학원이 자체 홈페이지를 갖는 비율이 높아서 생긴 결과지, 의도한 타겟팅이 아니다. 반대로 보습·수학·영어 학원은 A등급(홈페이지 없음)에 몰려 있다. **입시·보습 버티컬에 집중하려면 콜드 이메일이 아니라 전화가 주 채널이어야 한다** — PLAN.md의 채널 가정을 이 데이터로 재검토할 것
4. **마포구로 쏠렸다(21/51).** 홍대 일대에 자체 홈페이지를 운영하는 예체능 학원이 밀집해 있어 2차 수집이 그쪽에서 많이 걸렸다. 구별 균형을 맞추려면 강남·서초에서 추가 수집이 필요하다
5. **네이버 플레이스를 못 뚫었다.** 플레이스에만 적힌 이메일·영업시간·리뷰 수(=규모 신호)를 확보하지 못했다. IP 차단이 풀린 뒤 재시도하거나 수동 확인이 필요하다
6. **규모 판정이 층수 프록시에 의존한다.** 실제 원생 수·강사 수는 확인하지 못했다. 등록 정원은 과목당 정원이라 총 규모가 아니다
7. **프랜차이즈 판정은 검색 기반이라 오차가 있다.** 지역 2~3개관 운영 독립 학원을 프랜차이즈로 오분류해 제외했을 가능성이 있다. 아베크뮤직아카데미는 전 캠퍼스 공용 대표번호(1577-2507)만 공개돼 있어 홍대캠퍼스 직통 연결이 안 될 수 있다

## 발송 전 확인 사항

PLAN.md 기준으로 **KISA 불법스팸대응센터 준법 확인이 끝나기 전에는 콜드 아웃바운드를 전량(전화 포함) 개시하지 않는다.** 이 리스트는 게이트 통과 후 사용할 준비 자산이다. 발송 시 `(광고)` 표기, 전송자 명칭·연락처, 무료 수신거부 방법을 고정 포함할 것.

CSV의 `접촉일·채널·응답·다음액션` 4개 열은 발송 추적용 빈칸이다. PLAN.md의 접촉 이력 관리 항목(동의일시·동의방법·증빙)은 실제 발송을 시작할 때 열을 추가해 함께 기록할 것.
